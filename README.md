# GymTracker - ジムトレーニング記録アプリ

iPhoneで簡単にジムでのトレーニング記録を管理するアプリです。

## 機能

### 📱 ホーム画面
- **天気表示**：東京都豊島区の気温とアイコン表示
- **今日のメニュー**：曜日ごとのトレーニングメニューを自動表示
- **クイックアクション**：トレーニング開始、メニュー管理、過去データ確認

### 🏋️ トレーニング記録
- **自動タイマー**：曜日ごとに異なる時間設定可能（デフォルト70分）
- **セットごと記録**：各セットの回数を個別に入力
- **進捗表示**：前回の同じ曜日との比較で回数が増えた場合は「+」、減った場合は「-」を表示
- **記録保存**：トレーニング終了時に自動保存

### ⚙️ メニュー管理
- **曜日別管理**：7曜日すべてのトレーニング種目を管理
- **簡単編集**：種目の追加・削除・編集が可能
- **フレキシブル**：いつでもメニューを変更可能

### 📊 データ分析
- **進捗グラフ**：曜日ごとのトレーニングボリューム（総回数）を可視化
- **履歴確認**：過去のトレーニング記録を閲覧
- **自動保護**：端末内に最大20世代のバックアップを保存し、LocalStorageの消失・破損を検知したときに自動復旧
- **バックアップ移行**：JSONファイルへの書き出しと、バックアップファイルからの復元に対応

### ⏱️ 設定
- **タイマー時間カスタマイズ**：各曜日のトレーニング時間を個別に設定

## 使い方

### 初回セットアップ

1. `setup-menu.html` をブラウザで開く
2. 「メニューを自動登録」ボタンをクリック
3. `index.html` を開く
4. ホーム画面に表示される

### iPhoneへのインストール

1. Safari で `index.html` を開く
2. 下部のシェアボタン → 「ホーム画面に追加」
3. ホーム画面からアプリを起動

## 使用方法

### トレーニング開始
1. ホーム画面の「トレーニング開始」ボタンをタップ
2. 各種目のセットごとに回数を入力
3. 「開始」でタイマースタート
4. トレーニング終了後「トレーニング終了」をタップ

### メニュー管理
1. ホーム画面の「メニュー管理」をタップ
2. タブで曜日を選択
3. 種目を編集または「種目を追加」で新しい種目を追加
4. 自動保存される

### 設定変更
1. ホーム画面の⚙️をタップ
2. 各曜日のトレーニング時間を入力
3. 自動保存される

## データ保存

- すべてのデータはiPhoneのローカルストレージに保存されます
- 変更時・起動時・バックグラウンド移行時に、端末内の別領域へ最大20世代を自動バックアップします
- 過去データ画面からバックアップファイルを書き出し、同じ画面から復元できます
- クラウド同期はありません
- 端末の故障・紛失やサイトデータ全消去に備え、書き出したファイルをiCloud Driveなど端末外にも保存してください

## 技術仕様

- **フロントエンド**：HTML5 + CSS3 + JavaScript
- **ストレージ**：LocalStorage（主保存）+ IndexedDB（端末内世代バックアップ）
- **天気API**：Open-Meteo（無料）
- **グラフ表示**：Chart.js
- **PWA対応**：オフラインで動作可能

## 音声モードの試作（実機検証待ち）

ホームの「音声モードを試す」から `voice-test.html` を開けます。本体への記録連携は、iPhoneと使用する無線マイクで80分試験に合格するまで保留しています。試作は `gym_voice_prototype_v1` にだけ書き込み、本体のメニュー・記録・バックアップを変更しません。

1. iPhoneでは既存サイトと同じHTTPSの配信先で開きます。ローカルHTTPのLANアドレスではマイク・点灯維持が使えない場合があります。
2. 外付けマイクを接続し、他のトレーニング画面を閉じて「マイクを有効にする」を押し、必要な許可を与えます。点灯維持が有効か確認します。
3. 返答後に「筋トレ開始」「ベンチプレス70キロ3回」「5回」「4回」と発話します。当日のメニューと代替種目を利用し、メニューが空なら画面記載の3種目を試験用に使います。
4. 「訂正、6回」は直前セットの回数を変更、「今の取り消し」は直前セットを削除します。「72.5キロ」は以降の重量を変更します。種目切替後は重量も指定します。初版は数字と単位を含む短い発話に対応し、自由な長文の解釈は行いません。
5. 無言の休憩と5分ごとのタイマー音を含めて80分間使い、「筋トレ終了」「はい」で終了します。終了だけでなくセットごとに保存します。
6. 試作記録・診断ログをJSONで書き出し、実際の発話と照合します。80分経過は自動合格になりません。開始後のタップ不要、保存漏れ・二重登録なし、音声終了を満たした場合のみ合格とします。

認識停止後は自動再開し、無反応対策として45秒ごとにも再接続します。この切替中と読み上げ中は発話を受け付けない時間があります。権限拒否、停止処理のタイムアウト、読み上げ失敗、繰り返しの認識失敗では通知して停止します。画面を隠す・閉じる操作は中断として記録し、再開しても連続試験の合格扱いにはしません。通信やiOSの制約で復旧できない可能性は実機で確認してください。

音声認識サービスに音声が送信される場合があります。アプリには音声ファイルを保存せず、文字起こしと診断時刻を端末内に保存します。書き出したJSONにも文字起こしが含まれます。

PCでは「PCでコマンド動作を確認」の入力欄で操作確認できます。手動入力回数が記録され、音声試験の合格とは区別されます。検証コマンド：`node --test tests/voice-session.test.cjs tests/voice-runtime.test.cjs`（ビルド・追加パッケージ不要）。

### 試験後の連携作業

合格した機材・iOSバージョン・ログを確認後、既存フォームと途中保存を使うアダプターを追加します。音声終了では既存のalertを表示しない経路を使い、重量変更は過去セットに遡及させず、訂正・最終セットの取り消しも保存へ反映します。この試作段階では履歴への反映は意図的に行いません。

## 一般的な問題

### データが表示されない
- キャッシュをクリアして再度開く
- `setup-menu.html` でメニューを再登録

### 天気が表示されない
- インターネット接続を確認
- Open-Meteo APIが利用可能か確認

### タイマーが音を出さない
- ブラウザの音声設定を確認
- 通知許可を確認
